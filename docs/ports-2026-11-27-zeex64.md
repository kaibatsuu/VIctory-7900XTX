# Ports from zeex64/victory-7900xtx (`e2b05f4`, 2026-11-27)

Audited on 2026-11-27: [zeex64/victory-7900xtx](https://github.com/zeex64/victory-7900xtx)
at `e2b05f4` (8 commits past our shared ancestor `b0cfe2b`). Their tree descends
from `avatarmanz/VIctory-7900XTX` and adds Linux/Proton/vkd3d-proton fixes plus
a large suite of recording-thread, submission-thread, write-watch, pipeline,
and shader improvements.

All applicable improvements were adapted by hand onto `impl-cf-oppi-memtier`
in atomic commits, preserving our fork's existing features (self-healing
pipelines/canaries, renderer ports #1–#7, `VICTORY_HEAP_PACK`,
`VICTORY_POOL_DISCARD`, `VICTORY_LAZY_POOL_COMMIT`, `VICTORY_RT_RESOLVE`
default-skip, `VICTORY_SPANS_QUICK`, and the fork's baseline rule that visual,
semantic, or experimental switches default off on Windows).

## Ported

### 1. Loader & HLE diagnostics, skips, and `xmem` fast paths

- **Crash diagnostics** (`crates/victory-loader/src/crash.rs`,
  `crates/victory-hle/src/modules/xmem.rs`): `describe_on_crash` hook,
  `read_quietly`, and `memory_lines` print code bytes around RIP, register
  target memory, non-zero 4 KiB page counts, and recent `xmem` mappings/unmaps
  on both first-chance console reports and `crashes.log`.
- **`VICTORY_NO_WATCHDOG=1`** (off by default; `victory-loader/src/hooks.rs`,
  `windows.rs`): hash- and byte-checked patch of the title's watchdog routine
  (gated to main exe, never DLLs).
- **`VICTORY_SAMPLE=<ms>`** (diagnostics builds, off by default;
  `victory-loader/src/stacks.rs`): periodic stack sampling of title threads.
- **`VICTORY_SKIP_BINK=1|all`** and **`VICTORY_SKIP_INTRO=<sec>`** (off by
  default; `victory-hle/src/bink.rs`, `modules/gameinput.rs`,
  `apps/victory/src/run.rs`): Bink video skipping and timed intro input skip.
- **`xmem` optimizations** (`crates/victory-hle/src/modules/xmem.rs`):
  - `VICTORY_LIFT_SELDOM` (on by default; `=0` off): avoids redundant
    placeholder lifts when a view covers the range already.
  - `VICTORY_UNMAP_RUNS` (on by default; `=0` off): batches contiguous unmaps
    in runs (compatible with `VICTORY_POOL_DISCARD` and
    `VICTORY_LAZY_POOL_COMMIT`).
  - `VICTORY_MAP_SAME` (off on Windows, on under Wine; `=1`/`=0`): skips
    remapping pages already mapped identically.
  - `join_unasked()` fallback in `show()` and `RECENT` ring buffer for crash
    reporting.

### 2. Shaders

- **`VICTORY_NAN_GUARD`** (off by default; `=1` guards pixel colour exports,
  `=stores` also guards typed image/buffer float stores;
  `crates/victory-shader/src/emit/lower.rs`, `shader_cache.rs`): clamps
  NaN/Inf values; only hashed into the shader cache key when enabled so
  existing caches remain valid.
- **`VICTORY_SINGLE_LATCHES=1`** (off by default;
  `crates/victory-shader/src/emit/bitcode.rs`, `shader.rs`, `shader_cache.rs`):
  merges multiple loop back-edges to one latch block (reusing our zero-alloc
  `successors()`); only hashed into the shader cache key when enabled.
- **`PIPELINE_STACK`** (`256 << 20` in `victory-shader/src/emit/mod.rs`) for
  deep DXIL/SPIR-V recursion under Wine/vkd3d-proton.

### 3. Write watch & in-place memory safety and fast paths

- **`inplace::pinned`** (`crates/victory-gpu/src/inplace.rs`, `shadow.rs`,
  `watch.rs`): tracks 64 KiB blocks pinned by in-place heaps so
  `GetWriteWatch(RESET)` does not revoke GPU pinnings under Wine.
- **Guard lock & fault safety fixes** (`crates/victory-gpu/src/watch.rs`):
  - Re-entrant write fault recovery while holding `GUARDS` (`HeldWrite` /
    `HeldRead`, `opened_held`, adapted to Port #6's `RwLock<Guards>`).
  - `guard()` / `guard_shared()` avoid unlock/relock when `unsure` is empty.
  - `is_view()` rejects `MEM_FREE`; `protect_alias()` checks `g.foreign`;
    `protect_here()` verifies `MEM_COMMIT && MEM_MAPPED` while keeping our
    region cache.
  - `came_back` self-wait guard when `CHANGING` is already held by the current
    thread.
- **Refusal & placeholder caches** (`crates/victory-gpu/src/watch.rs`,
  `lib.rs`, `xmem.rs`):
  - `VICTORY_ASK_KNOWN` (on by default; `=0` off): caches recently refused
    ranges (`REFUSED`) and tracks runtime placeholder reservations (`ARENAS`
    via `title_memory_placeholder`) to skip guaranteed-failing kernel queries.
  - `VICTORY_HOLES_TOLD` (off on Windows, on under Wine; `=1`/`=0`): trusts
    runtime placeholder reservations when `NtQueryVirtualMemory` does not
    support placeholder info, plus `PLACEHOLDERS_UNKNOWN` and a 64-query cap
    in `look_at_holes`.
  - `VICTORY_TEXTURE_ASK_ONCE` (off on Windows, on under Wine; `=1`/`=0`):
    folds write-watched textures into the submission's `ask_once` pass.
- **`VICTORY_REMAP_LEAN`** (on by default; `=0` off; `watch.rs`): tracks
  in-flight remap ranges via `CHANGING_AT`, avoiding exclusive `GUARDS` write
  locks on `Remapping::drop`.
- **`VICTORY_GUARD_HOT_FRAMES=<frames>`** (off on Windows, `4` under Wine;
  `=0` off; `watch.rs`, `host.rs`): frame-based buffer-only hot-block tracking
  (`HotAsker` scoped to `Batch::update`), keeping Port #6's existing
  ms-based `VICTORY_GUARD_HOT` intact under its original name.

### 4. Pipeline, pool, resource, and texture fast paths

- **Empty pipeline library fix** (`crates/victory-gpu/src/pipeline/library.rs`):
  passes a real `NULL` pointer + length 0 to `CreatePipelineLibrary` when
  starting an empty library (vkd3d-proton rejects an empty Rust slice's
  dangling pointer with `E_INVALIDARG`).
- **`VICTORY_LEAVE_OUT=<hash>,...`** (`pipeline/make.rs`, `pipeline/known.rs`):
  skips compiling specified 16-char shader hashes (checked before isolation).
- **`VICTORY_LARGE_STACK`** (off on Windows, on under Wine; `=1`/`=0`;
  `pipeline.rs`, `pipeline/make.rs`): runs shader translation and pipeline
  creation on a 256 MiB stack (`PIPELINE_STACK`).
- **`VICTORY_FRESH_QUICK`** (on by default; `=0` off; `pool.rs`): lock-free
  `MADE_AT` fast path in `pool::fresh()`.
- **`VICTORY_PLACED_QUICK`** (on by default; `=0` off; `resource.rs`,
  `descriptor.rs`): `TARGETS_SEEN` Bloom filter in `alias_of()`, 2048-entry
  TLS `FOUND` cache in `texture_at()`, and 1024-entry TLS `SHAPES` cache in
  `descriptor::placed_quick()`.
- **`VICTORY_SWEEP_FOLLOWS_ROOM`** and **`VICTORY_SWEEP_GONE_FIRST`** (both
  on by default; `=0` off; `resource.rs`, `copystat.rs`): scales sweep
  thresholds with `VICTORY_TEXTURE_ROOM_PERCENT` and evicts placed textures
  whose title memory is already unmapped first, unified cleanly with our
  `VICTORY_HEAP_PACK=1` occupancy ranking.
- **`VICTORY_UPLOAD_ASKED`** (on by default; `=0` off; `texture.rs`): checks
  `list.used(...)` before taking `HOST_WRITTEN.lock()` in `upload_from()`.

### 5. Recording-path CPU optimizations & ambient reflections

- **`VICTORY_DYNAMIC_CHUNK=<n>`** (default `64`; `=0`/`=1` off; `draw.rs`,
  `descriptor/host.rs`): allocates dynamic descriptor slots in per-list chunks
  while at least half the dynamic pool is free.
- **`VICTORY_READY_FINE`** (on by default; `=0` off; `host.rs`, `draw.rs`):
  separates `HostList::moved()` from `HostList::epoch()` so a texture's first
  use in a list does not invalidate already-ready views and targets.
- **`VICTORY_ENTRY_READY`** (on by default; `=0` off; `draw.rs`,
  `descriptor.rs`, `descriptor/host.rs`): caches ready direct table entries
  per list via `HostHeap::quick_key()` and `descriptor::views_freed()` (with
  pre-mirror `views_freed()` capture to close the concurrent-forget race).
- **`VICTORY_TARGETS_ONCE`** (on by default; `=0` off; `draw.rs`): skips
  redundant render-target/depth state checks when nothing in the list moved
  and targets did not change (clearing `targets_ready` after the
  `VICTORY_BIND_CACHE` fast path).
- **`VICTORY_RETIRE_BATCH`** (on by default; `=0` off; `descriptor/host.rs`,
  `host.rs`, `draw.rs`, `list/thin.rs`): batches descriptor-slot resource
  retirements in thread-local scopes (`RetireScope`), stacking on top of our
  16-shard `RETIRED` queues.
- **`VICTORY_RECORD_BATCH`** (diagnostics builds, on by default; `=0` off;
  `list.rs`, `list/thin.rs`, `copystat.rs`): batches `copystat::recorded`
  clock reads across thin-recording chunks when timeline capture is off.
- `draw.rs::early_textures`: load-before-swap on `FRAME` to avoid cross-core
  cache-line bouncing across recording threads.
- **`VICTORY_AMBIENT_REFLECT=<part>`** (off / `0` by default here; try `0.5`;
  `ambient.rs`, `draw.rs`): clamps glossy reflections after `CS_UpdateHistory`
  to a share of the estimated ambient light (from beloooo's `44dcd437`,
  adapted to our 17-constant root signature alongside `VICTORY_AMBIENT_LEFTOVER`
  and `VICTORY_AMBIENT_SETTLE`).

### 6. Submission-thread parallelism & shadow refresh tuning

- **Beside worker** (`crates/victory-gpu/src/host/beside.rs`, `host.rs`,
  `shadow.rs`, `watch.rs`, `texture.rs`): overlaps independent submission
  stages on a dedicated `victory-beside` helper thread:
  - `VICTORY_ASK_BESIDE` (on by default; `=0` off): write-watch asking beside
    `card_steps` planning, invalidated if flights landed in between.
  - `VICTORY_REFRESH_BESIDE` (on by default; `=0` off): ahead-of-steps buffer
    refreshes beside `stale_under_flights`, invalidated via
    `shadow::ranges_done_with()` if a declared range completed concurrently.
  - `VICTORY_SNAPSHOTS_BESIDE` (on by default; `=0` off): snapshot copies
    beside `card_before`.
  - `VICTORY_BESIDE_SPIN=<us>` (default `500`; `=0` off): spin window between
    stages on `victory-beside`.
- **`host/card_steps.rs`**: removes `Box<dyn Iterator>` heap allocation per
  step in `plan()`.
- **`VICTORY_GAPS_TOGETHER`** (on by default; `=0` off; `shadow.rs`): batches
  gap refreshes around in-flight shader writes into one parallel `take_parts`
  pass.
- **`VICTORY_WIDE_MORE=1`**, **`VICTORY_TAKE_FINE=1`**,
  **`VICTORY_POOLS_MORE=1`** (all off by default; `shadow.rs`, `land.rs`):
  optional wider worker pools and finer refresh chunking (256 KiB / 64 KiB).
  Preserves our lock-free `Done` gate and targeted `notify_one()`, and spawns
  spare threads lazily only when enabled or listed in `VICTORY_AB`.
- **`VICTORY_CARD_FINE=1`** (off by default; `shadow.rs`, `host.rs`): AVX2
  256-byte diffing for card-resident copies before upload, with unit tests in
  `shadow::fine_tests`.

## Read and left out, with reasons

- **RT resolve default inversion (`without_structures` / `shades_hits_left_out`)**:
  our `pipeline/host.rs` already skips `CS_RaytracingResolve` (and
  `CS_ScreenProbes_ActivateRays`) by default unless `VICTORY_RT_RESOLVE=1` or
  `VICTORY_BVH_BUILDER=1`.
- **Custom Wine kernel view write-tracking (`VIEW_WATCH`, `VIEW_WATCH_USE`,
  `VIEW_WATCH_ALL`)**: requires a custom Wine kernel patch (`views-writewatch`)
  and was not used on Windows (or even enabled by default in zeex64's notes).
- **Wine view-coalescing in `xmem` (`JOIN_VIEWS`, `SCATTER_RUNS`,
  `ALIAS_RUNS`, `ALIAS_BATCH`, `MAP_KNOWN`, `views_regrouped`)**: disables our
  8-thread Windows `side_by_side()` mapper and conflicts with
  `VICTORY_POOL_DISCARD` and `VICTORY_LAZY_POOL_COMMIT`.
- **Always-on 5-second `xmem` census logs**: acquires the `PHYSICAL` lock in
  release builds and is redundant with `stream_log` and `memory_stats_line`.
- **`descriptor/host.rs` `Spans::known`**: superseded by our existing
  `HostHeap::spanned` + `VICTORY_SPANS_QUICK` + `SPANNED` bounds.
- **`linux/` scripts and Wine/vkd3d patches** (and widening
  `xtask/src/policy.rs` to allow `.patch`/`.c`/`.example`): omitted to keep
  the repository's strict asset policy intact on this Windows fork.
